# 多维分析法（MDPAF）B6

## 概述

本 skill 装载 esf 原创的「多维分析法」B6 全套思想，用于对任何「要不要做、做得对不对、该不该继续」的对象执行一次完整、防幻觉的判定分析。核心模型是「行为区块链」——把想法放回用户世界的长链中定位，按范围配价值判断。

**执行本 skill 前，必读 `references/mdpaf-methodology.md` 全文**（B6 权威文本，约六千字）。方法论不在本文件里重复——本文件只装工作流程与纪律。

## 工作流程

### 第一步：就位与盘点

1. 确认分析对象。若用户尚未给出项目资料：声明待命，不提前分析、不凭名字或描述猜测项目内容。
2. 资料到位后先盘点：列出已有什么（项目说明、用户数据、竞品信息、付费证据）、缺什么。**缺口如实标注「待补充」并向用户直问事实**（谁掏钱、掏过多少、痛多久一次、现在怎么凑合）——不问观点，问发生过的事。
3. 每条关键事实标注来源：用户提供 / 公开检索 / 推断 / 待补充。

### 第二步：执行 B6 全流程（一步不省）

按 `references/mdpaf-methodology.md` 的次序执行，全程不许抄近路、不许跳层：

1. **粗守**：有没有人为声称的痛点付出过代价？不真 → 就地终止，如实报告死在粗守。
2. **延伸**：把对象放进用户世界的完整大链，前后左右画图（只画图、不判断），延伸停点 = 最近用户任务闭环。
3. **重切**：在大链下定案实际覆盖哪几个区块；**并排显影**（声称覆盖 vs 实际覆盖，不同则分析转向新块）；记录**覆盖修正**。
4. **细守**：对实际覆盖的块过痛点七问全检（真 / 量 / 解 / 志 / 度 / 凑）+ 时机问「为什么是现在做」。粗守的证据属于旧块的，不自动传承。
5. **下尺**：按范围挂判断——大链挂天花板量级与漂移信号；区块组挂介入价值、断链、付费三角；核心块挂在场者（含土办法、用户的志、让步的重量、加分项硬约束）、满意度与切换成本、付费触发点、机会公式（区块级）、保质期。
6. **改善**：收束为有据结论 + 排序标价的行动；**结论不得引入新证据**；允许「最好的改善就是不改善」。
7. **扩展**：四向生长候选（上游 / 下游 / 并联 / 变形），每个候选过三道闸（回炉 / 相邻 / 优先）。

### 第三步：交付（对话内七段结构）

1. **最终判定**：七选一原词——加码 / 继续 / 补完 / 修复 / 下线 / 砍掉 / 待定，附一句话理由；若细守未通过，写明**死在哪一问**。
2. **守门结论**：粗守、细守各自通过与证据摘要。
3. **大链图与显影**：延伸出的大链结构（可用文字链或图）、声称覆盖 vs 实际覆盖并排、覆盖修正。
4. **逐块判断**：核心块的在场者、分量、满意度与切换、让步重量、机会公式结论——逐块给，不笼统。
5. **改善收束**：排序标价的行动清单，每条能回答「先做哪个、花多少、怎么算做成了」。
6. **扩展候选**：候选清单 + 三道闸筛选结果。
7. **待补充清单**：材料缺口，逐条写成直问事实的问题。

用户要短版时，改交付**五问速览**：值不值得做 / 对手是谁（含土办法）/ 对手缺什么 / 我们有什么对手没有的 / 怎么改、扩展、删——外加时机（为什么是现在）。

## 硬纪律

1. **不编造**：资料里没有的竞品、用户行为、付费证据，一律标「待补充」，不许脑补；「没人做过」不是「没解法」的证据。
2. **技术力判断不许凭记忆**：凡涉及「现有技术力到哪了、解法近两年是否变强」的判断，必须实时检索核实；无法检索时，明确标注「基于知识截止于 X 年 X 月，需人工复核」。判据限定现有技术的自然延伸，不预测科幻级跃迁。
3. **机会判断必须标保质期**：剩余空间须标「按当前技术力能守多久、何时复刻」——没标复验时点的机会判断视为未完成。
4. **结论不加新证据**；行动必须排序标价，禁写「加强」「优化」类愿望。
5. **不利结论照样给足**：本方法量的是掌握度，不是好消息；判定只用七选一原词，不自创判定词。
6. **次序不可交换**：跳序、跳层得到的一切答案都视为无地基，须回退重走。
