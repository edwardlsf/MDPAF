## 1. 提示词正文（以下内容原样交给 AI）

你刚刚（或即将）按「多维分析法」对某项目完成了一次完整分析。现在把分析结果整理成一份**人类阅读版报告**，并输出为 PDF。

### 1.0 方法论（内联自《多维分析法_B6》全文思想部分；源头文件独立存在，本节与源头冲突时以源头为准）

#### 1.0.1 这套方法是什么

「多维分析法」是一套判定、分析、改善、扩展某个对象（产品 / 项目 / 作品 / 功能 / 想法）的思想方法。

**一句话说尽这套方法**：用「是否有人付出过代价」判真伪（守门两遍，细守扩为痛点七问全检：真、量、解、志、度、凑，收尾加问时机「为什么是现在」），把想法放回用户世界的长链中定位（延伸建坐标 → 重切定范围），再**按范围配价值判断**（落差、在场者、位置、掏钱——挂在各自所属的层上），用「有据结论 + 排序标价的行动」收束，沿链四向生长但每个候选回炉重审——全程相信成本、不信口号，并随时准备重画地图。

**「多维」由此得名**：不只一把尺子（多组价值判断），也不只一层范围（宏微观分层）——层与尺子组合起来，才是全貌。

#### 1.0.2 四个动词

方法论的本体是四个动词：**判定 → 分析 → 改善 → 扩展**。它们构成一个循环：扩展生成的新对象，回到判定重新走一遍。

统一表述：四个动词，全部是「对范围做动作」——

| 动词 | 对范围做什么 |
|---|---|
| **判定** | 对最粗的范围（想法声称覆盖的块）守门 |
| **分析** | 延伸建坐标 → 重切定范围 → 按范围配判断 |
| **改善** | 对已知全部范围收束行动 |
| **扩展** | 生成新的范围候选，扔回判定 |

**1. 判定——「值得吗？」（守门第一遍：粗守）**

在投入任何分析资源之前，先用一个极低成本的问题试探真实性：

> **有没有人已经为这件事付出过代价？**（时间、钱、麻烦，都算）

- 痛过的人才会掏钱、花时间、忍受麻烦。没人为它痛过的东西，再精致的分析都是给幻觉做装修。
- 这是整个方法的守门员：判「不真」，就地终止，成本归零。
- 口头说想要、客套夸不错，都不算付出代价——只有真实发生的成本行为才算数。
- 本动词守的是**粗守**（第一遍）：对象是发起人**声称**的痛点块，目的在零成本滤掉明显幻觉。延伸重切之后范围可能位移，位移后还要**细守**（守门第二遍，见分析第二步）——B4 起，细守从单一问题扩为**痛点七问全检**。

**2. 分析——「延伸 → 重切 → 下尺」**

分析不是一列依次出场的尺子。**区块切割负责划定范围，尺子负责在范围上判断价值**——所以不存在「尺子何时进入」的问题，只存在「对哪个范围、做哪组价值判断」的问题。分三步：

**第一步：延伸——建坐标系（在用户的世界里定位）**
- **想法不是范围的顶层**。你的项目 / 想法，几乎总是长链中间的一个区块——宏微观之间的中间，嵌在用户世界的一条大链上。若以「想法整体」为坐标原点，等于用发起人的自我边界画地图——这是「分母乱画」的隐蔽形态：分母写着「用户视角」，实际画的是自己。
- 操作：把想法放进它所在的大链（用户办成这件事的完整过程），**向前后左右延伸扫描**，画出大链的完整形状——你前面的块（用户在你之前做什么）、你后面的块（之后做什么）、并联的块（同时进行的支路）。这一步只画图、不判断、不取舍。
- **延伸停点（任务锚点）**：延伸到「能看清对象位置的最近用户任务闭环」为止（一顿饭办完了、一次出行办完了——用户任务的完成信号）。**锚点分层复用**：阶段锚点（菜上桌、筷子放下）切区块，任务锚点定大链边界——锚点是整个范围轴的通用刻度，不无限上溯。

**第二步：重切——定案范围（并排显影 + 覆盖修正 + 细守）**
- 在大链坐标系下重新审视切割：你的想法实际覆盖大链上的哪几个区块？切法跟**用户的阶段感**走、用**聚分双检**定案（换得动邻居且在别的有效组合中稳定存在 = 独立一块；相邻区块换了任何一段就散 = 强相关 = 合并为一个大区块，进入子链才逐块拆——两个检验都以声明的闭环目标为前提；倾向性判据，灰带回停拆规则）。
- **并排显影（防自我说服）**：把「延伸前你声称覆盖的块」与「重切后实际覆盖的块」并排写出来。两者不同时，后续全部分析必须转向**新块**——不许沿用旧的痛点描述。已为画链付出的功夫不是理由：沉没成本会推着你论证「实际上还是我原来那块」，显影就是为了把这动作堵死。
- **覆盖修正**：范围位移的方向与大小，本身就是本次分析的第一个产出——它常常就是产品定位真正该调的地方，如实记录。
- **细守（守门第二遍，B4 起扩为痛点七问全检）**：范围定案后，对**实际覆盖的这些块**过一遍七问——①**真**：用户为它们付出过代价吗（原细守问题）；②③**量**：有多痛 × 有多少人痛（强度 × 广度 = 痛的总账）；④**解**：有解法吗（没解法问能不能被解决，有解法逐个登记在场者）；⑤**志**：用户自己要解决吗（他为「摆脱」付出过动作吗——你替他急不算）；⑥**度**：现有解法解了多少（解掉百分比 + 让步的重量 + 加分项硬约束，见分析第三步在场者；百分比有保质期——按当前技术力能守多久，见信念三推论三）；⑦**凑**：痛完之后呢（土办法——真实起跑线）。七问过完，**补一问时机（B6 新增）：「为什么是现在做？」**——现有技术力刚刚够到 = 窗口刚开（B5 埋伏位的兑现时刻，先占者优势最大）；技术力早就够到却无人做成 = 回头重查④（坟场）与⑤（志）——「没人做」要么有原因，要么有尸体，两种都要问出来。粗守时引用的证据若属于旧块而新块不同，不自动传承，要补新证据。粗守 + 细守 = 守门两遍：先省成本（滤幻觉），再保坐标（七问对准新块）。

**第三步：下尺——按范围配判断**

不存在「四把尺子依次出场」，存在的是**范围决定判断组合**：

| 范围 | 挂载的价值判断 |
|---|---|
| **大链**（延伸出的坐标系） | 天花板量级（长链 / 短链）；漂移信号：哪几个块正在技术、习惯、政策下变大变小 |
| **对象覆盖的区块组**（重切定案的） | 细守（付出代价重认）；介入价值（重块几个、卡口与否、断链否）；付费三角（对象级角色）；总盘生意 |
| **核心区块**（重区块与卡口；轻块少挂） | 在场者与土办法（这块谁在凑合）、用户的志（要解决吗）、分量（时间 / 难度 / 重复度 / 成本 / 范围）、满意度与切换成本、让步的重量与加分项硬约束、付费触发点、机会公式（区块级，见下）、放大观察（子链与子链卡口） |
| **候选区块**（扩展生成的） | 回炉全检：候选不豁免，走「延伸 → 重切 → 下尺」全流程 |

- **挂载密度控制**：重区块与卡口全挂，轻区块少挂——与停拆规则同构：问题不问的层不拆，问题不问的块不挂。
- **机会公式下沉（区块级）**：机会 = **该区块**的现有解法满意度低，且换到你的方案成本低。机会不再是一句链级总判断，而是逐块的局部判断——同一张链上往往几块是机会、几块是陪跑，笼统一句「有机会」掩盖的正是这个。

各组判断的要点（挂到各自的范围上）：

**落差（对象级）**——「想解决的 / 能解决的 / 实际解决的」拆三段：「想 vs 能」落差 = 设计问题，「能 vs 实际」落差 = 落地问题，两种病药方不同；「想解决」原文照录；「实际解决」须有实测证据，无则如实标注。

**在场者（区块级）**——这块上谁已经在解？土办法（用户此刻的凑合办法）是真竞品；满意度要分「骂着用」（有东西拴着，别碰）与「骂完就走」（机会）；切换成本要拆（钱、数据搬家、习惯、关系、重学）；**用户的志**（B4 新增）：用户自己想摆脱吗——判据是「摆脱动作」（找过替代、试过工具、花过钱），你替他急不算；**让步的重量**（B4 新增）：现有解法解不到的部分，用户怎么让步（忍、绕、拼凑、放弃）——让步越轻剩余痛越不值钱，让步越重切入点越大；**加分项硬约束**（B4 新增）：「解完原痛还顺带……」的额外收益，必须有人为那个加分项**单独**付出过代价才算数，否则只记不评；解法两个方向——没解法问「能不能被解决」（不能 = 科学问题非产品问题），有解法问「复制难度」（容易 = 谁都进得去，很难 = 破局资格或出局）；坟场是警告不是蓝海；**抄袭是双向的**：别人好不好被你抄（复制难度），你好不好被别人抄（护城河），两边都查。

**掏钱（对象级三角 + 区块级触发）**——使用者、决策者、付费者逐个指名；不重合时一切动作对准掏钱的那个（话术说给买单的人听）；每块有各自的痛感峰值，收费点贴着触发点。

**3. 改善——「下一步做什么？」**

分析完毕，收束成两样东西，守两条铁律：
1. **结论不得引入新证据**。收束时只准使用前面查明的事实——防止临场编故事、防止结论逃逸出证据。
2. **行动必须排序并标价**。不许写「加强」「优化」这类不花成本、无法验收的愿望；每条行动要能回答「先做哪个、花多少、怎么算做成了」。

允许一个反直觉的答案：**最好的改善就是不改善**。有的对象，结论就是「停」，行动清单上第一条是「停止投入，成本为零」。

**4. 扩展——「链上还能长什么？」**

位置定案之后（定在延伸建好的大链坐标系上），沿链向四个方向扫描生长候选：

| 方向 | 含义 |
|---|---|
| **往上游** | 占住排在你前面的区块（做分发的前去做创作） |
| **往下游** | 占住排在你后面的区块（做交易的前去占支付） |
| **并联** | 长出共享同一批资源的旁支（司机与算法可复用，就长代驾） |
| **变形** | 不占新位置，改造链本身：拆、并、增、删 |

生长必须过三道闸，缺一不可：
1. **回炉闸**：每个新候选不享受任何豁免，回到「判定 → 分析」从头全审一遍（延伸、重切、细守、逐块判断一样不少）。生成候选的成本是零，最容易诱发幻觉。
2. **相邻闸**：只许长在与现有位置共享「用户 / 能力 / 资源」的地块上。链上相邻 ≠ 能力相邻——离得近不等于做得成。
3. **优先闸**：同等条件下，优先占卡口，其次占重区块，最后才是轻区块。

**原则：生长负责大胆，分析负责杀。**

#### 1.0.3 贯穿的三个信念

三个信念撑起全部四个动词。动词是手法，信念是魂。

**信念一 · 顺序即逻辑**

判定 → 分析 → 改善 → 扩展的次序不可交换：痛点不真，谈竞争无意义；空位不在，谈位置无意义；位置不对，谈收钱无意义。后面的问句永远建立在前一问通过之上。跳序得到的所有答案，都建立在没验证的地基上。范围层的粗细也在次序里：粗守在延伸前，细守在重切后，尺子在定案后——跳层得到的所有答案，同样没地基。

**信念二 · 成本是唯一的测谎仪**

口号不算数，点赞不算数，情怀不算数——只有「付出过代价的行为」算数。这套方法里最锋利的判断都源于此：土办法是真竞品（用户已经为它付出了习惯）；骂着用不是机会（他忍的成本低于走的成本）；付费瞬间是痛点发作那一刻（此刻他最愿意掏钱）；阶段边界看锚点不看时长（用户为自己的分段付出了认知）；用户的志看摆脱动作不看嘴上说（行动有成本）；让步的重量量的是用户已经在付的成本；粗守细守两遍都是成本检验（有人付出过代价吗）。分析中的一切疑点，最后都问一句：**有人为它花过什么吗？**

**信念三 · 地图会过期**

链上的区块会被技术、习惯、政策改变大小——某个区块可能被新工具压扁，价值不消失，迁往相邻区块（支付被压扁后，价值流向了数据与信贷）。递归结构下漂移可以发生在任何层：上层区块被压扁，子链随之重组；区块替换本身是漂移的聚合面（「自煮」被「点外卖」替换时，结构锚「吃饭」不变）。**漂移也发生在解法上（B5 新增）**：新解法会随技术力提升冒出来，旧解法会随技术力提升变强——「没解法」可能只是技术还没到（时间问题，不是科学问题），「解了七成」的剩余空间可能被对手的技术进步直接吃掉；判据限定**现有技术在当前提升速度下的自然延伸**，不预测科幻级跃迁。三个推论：① **一切结论有保质期**——今天是卡口，明天可能被压平，评估结论要定期重验；② **漂移即信号**——「哪一块正在变大」本身就是下一个生长方向的提示，扩展开扫前，先看链上哪里正在隆起；③ **机会有保质期（B5 新增）**——细守与在场者量出的剩余痛空间，必须标注「按当前技术力能守多久、何时复刻」，没标复验时点的机会判断视为未完成。

#### 1.0.4 核心模型 · 行为区块链

本方法的位置坐标系是**行为区块链**（作者原创概念）：用户视角的**最小完整闭环**（从起心动念到「办完」）由多个**行为区块**连接而成。构造规则：**阶段感切割**（边界跟用户心理分段走，物理锚点找边界，物理量是切块后的测量不是切割依据）；**递归结构**（没有绝对的宏观与微观，区块放大即子链）；**选层声明**（分母分层，分析前声明在哪一层画闭环）；**停拆规则**（拆到能回答当前问题为止）；**聚分双检**（见分析第二步）。断链 = 断在用户阶段感认为「还没完」的衔接处；卡口 = 「不过就全断」的块。

#### 1.0.5 方法适用什么、不承诺什么

- **适用对象**：产品、项目、作品、功能、想法——任何「要不要做、做得对不对、该不该继续」的对象。
- **天生缺口**（诚实声明）：外部约束（政策法规、时机窗口）与执行者能力（同一想法换人做，结论应当不同）不在这套方法的地基里；方法论类对象的守门适用性未建立。使用时另行补位，发现重大项写入报告「方法边界」。
- **不承诺**：全部公开案例来自已知成败的商业史，属于事后归纳，事前预测力尚无验证记录；本方法不保证结论正确，只保证**结论有据可查、行动可验收**——价值在防幻觉，不在预言。

#### 1.0.6 最终判定（七选一）

加码 / 继续 / 补完（实际解决待验证）/ 修复（有致命问题）/ 下线（已被取代）/ 砍掉（守门不过或坟场确认）/ 待定（证据不足）——不许自造选项。

### 1.1 你必须遵守的五条纪律

1. **先分析后成文**：本报告的每一个结论都必须来自按上方 1.0 方法论（即 B6 口径）执行的完整分析。没有跑过分析就生成报告 = 作废。若用户只给了项目名与材料，先自行完成 B6 全流程分析，再进入排版。
2. **简体中文**：文件名、正文、表格、图注、页眉页脚，全部简体中文（数字、下划线除外）。禁止出现繁体字。
3. **诚实不加妆**：结论与项目方的期待冲突时照实写；判定为「砍掉」「待定」就大方写出来——本报告的价值在让人看清，不在让人高兴。证据标注【实测】/【推断】/【假设】随文保留，无证据写「待验证」。
4. **重点前置**：人类最关心的答案必须在**第 2 页**全部出现（见 1.3 五问）。后面的页面是给想深究的人准备的，不允许把关键结论藏到第 5 页之后。
5. **文件名与时间**：输出 PDF 命名为 `项目名_多维分析_人读版_年年月月日日时时分分.pdf`（例：`示例项目_多维分析_人读版_202610092314.pdf`）；分析时间用 `date` 命令现取 12 位连续数字，不预估。
6. **技术力判断不许凭记忆（B6 新增，与《布置》系同源纪律）**：凡涉及「现有技术力到哪了、解法近两年是否变强」的判断，必须实时检索核实；无法检索时，明确标注「基于我的知识截止于 X 年 X 月，需人工复核」——AI 的知识截止日就是一张旧地图，用旧地图量技术曲线等于用过期地图导航。

### 1.2 报告结构（按序）

**第 1 页 · 封面**：
- 项目名（大标题）+「多维分析 · 人读版」副题；
- 分析口径：多维分析法 B6（痛点分析法已并入·机会有保质期·含时机问）· 完整版；
- 分析时间（date 现取）· 分析对象一句话 · 事实输入方与编制方（人工 / AI 分开标注）；
- 若有上一版报告：注明上一版口径与时间，本版为全量重审还是增量修订。

**第 2 页 · 重点速览（人类只看这一页也能拿走全部决策要素）**——五问五答，每问一段话直接给结论，禁止「详见后文」式空指针：

| 问题 | 回答什么（来自哪个分析产出） |
|---|---|
| **① 值不值得做？** | 最终判定（七选一：加码 / 继续 / 补完 / 修复 / 下线 / 砍掉 / 待定）+ 一句话理由 + 粗守细守是否通过 + **时机（为什么是现在：技术力刚够到 = 窗口刚开 / 早就够到却无人做成 = 有原因还是有尸体）** |
| **② 对手是谁？** | 核心块上的在场者：直接竞品逐个点名 + 土办法（用户现在的凑合方式）+ 坟场情况（做过的人死了没有） |
| **③ 对手缺什么？** | 现有解法（含土办法）的满意度缺口：用户骂什么、忍什么、凑合时最痛的那一刻；切换成本的构成 |
| **④ 我们有什么对手没有的？** | 我方与对手的差异点逐条列——同时做**双向核查**：这些差异对手抄来难不难（复制难度）+ 我们的护城河候选（写不出就写「无」）；若无任何对手没有的东西，如实写「暂无差异点」，这是最重要的诚实 |
| **⑤ 怎么改、扩展、删？** | 改善方向（ROI 排序 + 成本粗估 + 验收标准）、扩展候选（过三道闸后的）、建议删掉 / 暂缓的部分——三张小清单 |

第 2 页顶部放「最终判定」一行大字；五问表格之后附标注口径一行（【实测】/【推断】/【假设】的定义）。

**第 3 页起 · 分析正文**（给想深究的人，按 B6 范围轴组织）：
- 维度 0 粗守门（声称痛块 + 证据）；
- 维度 1 延伸（大链区块图：可用 HTML/CSS 盒图或内嵌 SVG 画，标卡口、并联、任务锚点）；
- 维度 2 重切定范围（并排显影表 + 覆盖修正 + 细守结论：七问全检 + **时机问**「为什么是现在」）；
- 维度 3 下尺（链级 / 对象级 / 核心块级三组判断，逐块标记：机会 / 陪跑 / 引流 / 暂缓）；
- 维度 4 总账（付费三角、收入、成本、护城河、复制难度双向核）；
- 维度 5 收束（结论 + 改善方向排序表：序号 / 行动 / 成本粗估 / 验收标准）；
- 生长扫描（若判定为加码 / 继续）：候选清单 + 三道闸结论。

**末页 · 附录**：
- 来源与冲突记录（【实测】证据的出处逐条列；多个来源打架时如实记录）；
- 方法边界（合规 / 时机 / 执行者能力方面的悬而未决项）；
- 术语小表（坟场检查、护城河、付费三角、七选一判定、机会保质期、埋伏位、时机问——给第一次接触 B6 的读者）。

### 1.3 排版与输出要求

- **HTML → PDF**：先写自包含 HTML（内嵌样式，不依赖外部资源；图用内嵌 SVG 或 CSS 盒图），再用无头浏览器转 PDF（Edge：`--headless --disable-gpu --no-pdf-header-footer --print-to-pdf`）；A4 纵向、白底、打印友好、每页带页眉（报告名 + 口径 + 日期）与页码。
- **第 2 页纪律**：速览页独立成页，信息密度可以高（表格、加粗、色块），但每条结论必须完整可读——人类跳过其余所有页也能据此决策。
- **图表自解释**：每张图带图例与图注；不使用需要上下文才能看懂的颜色。
- **PDF 生成后自检**：用 PDF 库（如 pypdf）验证页数与第 2 页五问齐全；报告旧文件不覆盖，新文件名含新时间戳。
- **语言自查**：生成后全文检索繁体字（常见：專項/報告/時間/後/裡），发现即改为简体。

### 1.4 质量红线（违反任何一条 = 重做）

1. 第 2 页缺五问中任何一问；
2. 结论出现分析过程中没有的证据（收束不加新料）；
3. 无证据的数字不带「待验证」标注；
4. 判定不是七选一词汇（自造新词）；
5. 繁体字残留；
6. 文件名不含 12 位时间戳，或时间戳为预估而非 date 现取；
7. 机会判断没标「能守多久 / 何时复刻」（推论三），或技术力判断未检索也未标注知识截止。
