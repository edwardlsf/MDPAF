## 0. 这份文件是什么

「多维分析法」是一套判定、分析、改善、扩展某个对象（产品 / 项目 / 作品 / 功能 / 想法）的思想方法。

本文只写方法论本身——它的四个动词、它们的次序、以及支撑它们的信念。**不写任何执行工艺**：没有模板、没有打分表、没有输出格式、没有操作流程。那些是派生品，不属于思想。

**一句话说尽这套方法**：用「是否有人付出过代价」判真伪（守门两遍，细守扩为痛点七问全检：真、量、解、志、度、凑），把想法放回用户世界的长链中定位（延伸建坐标 → 重切定范围），再**按范围配价值判断**（落差、在场者、位置、掏钱——挂在各自所属的层上），用「有据结论 + 排序标价的行动」收束，沿链四向生长但每个候选回炉重审——全程相信成本、不信口号，并随时准备重画地图。

**「多维」由此得名**：不只一把尺子（多组价值判断），也不只一层范围（宏微观分层）——层与尺子组合起来，才是全貌。

## 1. 四个动词

方法论的本体是四个动词：**判定 → 分析 → 改善 → 扩展**。它们构成一个循环：扩展生成的新对象，回到判定重新走一遍。

统一表述：四个动词，全部是「对范围做动作」——

| 动词 | 对范围做什么 |
|---|---|
| **判定** | 对最粗的范围（想法声称覆盖的块）守门 |
| **分析** | 延伸建坐标 → 重切定范围 → 按范围配判断 |
| **改善** | 对已知全部范围收束行动 |
| **扩展** | 生成新的范围候选，扔回判定 |

### 1.1 判定——「值得吗？」（守门第一遍：粗守）

在投入任何分析资源之前，先用一个极低成本的问题试探真实性：

> **有没有人已经为这件事付出过代价？**（时间、钱、麻烦，都算）

- 痛过的人才会掏钱、花时间、忍受麻烦。没人为它痛过的东西，再精致的分析都是给幻觉做装修。
- 这是整个方法的守门员：判「不真」，就地终止，成本归零。
- 口头说想要、客套夸不错，都不算付出代价——只有真实发生的成本行为才算数。
- 本动词守的是**粗守**（第一遍）：对象是发起人**声称**的痛点块，目的在零成本滤掉明显幻觉。延伸重切之后范围可能位移，位移后还要**细守**（守门第二遍，见 1.2 第二步）——细守为**痛点七问全检**。

### 1.2 分析——「延伸 → 重切 → 下尺」

分析不再是一列依次出场的尺子。**区块切割负责划定范围，尺子负责在范围上判断价值**——所以不存在「尺子何时进入」的问题，只存在「对哪个范围、做哪组价值判断」的问题。分三步：

#### 第一步：延伸——建坐标系（在用户的世界里定位）

- **想法不是范围的顶层**。你的项目 / 想法，几乎总是长链中间的一个区块——宏微观之间的中间，嵌在用户世界的一条大链上。若以「想法整体」为坐标原点，等于用发起人的自我边界画地图——这是「分母乱画」的隐蔽形态：分母写着「用户视角」，实际画的是自己。
- 操作：把想法放进它所在的大链（用户办成这件事的完整过程），**向前后左右延伸扫描**，画出大链的完整形状——你前面的块（用户在你之前做什么）、你后面的块（之后做什么）、并联的块（同时进行的支路）。这一步只画图、不判断、不取舍。
- **延伸停点（任务锚点）**：延伸到「能看清对象位置的最近用户任务闭环」为止（一顿饭办完了、一次出行办完了——用户任务的完成信号）。**锚点分层复用**：阶段锚点（菜上桌、筷子放下）切区块，任务锚点定大链边界——锚点是整个范围轴的通用刻度，不无限上溯。

#### 第二步：重切——定案范围（并排显影 + 覆盖修正 + 细守）

- 在大链坐标系下重新审视切割：你的想法实际覆盖大链上的哪几个区块？切法跟**用户的阶段感**走、用**聚分双检**定案（换得动邻居且在别的有效组合中稳定存在 = 独立一块；相邻区块换了任何一段就散 = 强相关 = 合并为一个大区块，进入子链才逐块拆——两个检验都以声明的闭环目标为前提；倾向性判据，灰带回停拆规则）。
- **并排显影（防自我说服）**：把「延伸前你声称覆盖的块」与「重切后实际覆盖的块」并排写出来。两者不同时，后续全部分析必须转向**新块**——不许沿用旧的痛点描述。已为画链付出的功夫不是理由：沉没成本会推着你论证「实际上还是我原来那块」，显影就是为了把这动作堵死。
- **覆盖修正**：范围位移的方向与大小，本身就是本次分析的第一个产出——它常常就是产品定位真正该调的地方，如实记录。
- **细守（守门第二遍，痛点七问全检）**：范围定案后，对**实际覆盖的这些块**过一遍七问——①**真**：用户为它们付出过代价吗（原细守问题）；②③**量**：有多痛 × 有多少人痛（强度 × 广度 = 痛的总账）；④**解**：有解法吗（没解法问能不能被解决，有解法逐个登记在场者）；⑤**志**：用户自己要解决吗（他为「摆脱」付出过动作吗——你替他急不算）；⑥**度**：现有解法解了多少（解掉百分比 + 让步的重量 + 加分项硬约束，见 1.2 第三步在场者；百分比有保质期——按当前技术力能守多久，见 2.3 推论三）；⑦**凑**：痛完之后呢（土办法——真实起跑线）。七问过完，**补一问时机：「为什么是现在做？」**——现有技术力刚刚够到 = 窗口刚开（埋伏位的兑现时刻，先占者优势最大）；技术力早就够到却无人做成 = 回头重查④（坟场）与⑤（志）——「没人做」要么有原因，要么有尸体，两种都要问出来。粗守时引用的证据若属于旧块而新块不同，不自动传承，要补新证据。粗守 + 细守 = 守门两遍：先省成本（滤幻觉），再保坐标（七问对准新块）。

#### 第三步：下尺——按范围配判断

不存在「四把尺子依次出场」，存在的是**范围决定判断组合**：

| 范围 | 挂载的价值判断 |
|---|---|
| **大链**（延伸出的坐标系） | 天花板量级（长链 / 短链）；漂移信号：哪几个块正在技术、习惯、政策下变大变小 |
| **对象覆盖的区块组**（重切定案的） | 细守（付出代价重认）；介入价值（重块几个、卡口与否、断链否）；付费三角（对象级角色）；总盘生意 |
| **核心区块**（重区块与卡口；轻块少挂） | 在场者与土办法（这块谁在凑合）、用户的志（要解决吗）、分量（时间 / 难度 / 重复度 / 成本 / 范围）、满意度与切换成本、让步的重量与加分项硬约束、付费触发点、机会公式（区块级，见下）、放大观察（子链与子链卡口） |
| **候选区块**（扩展生成的） | 回炉全检：候选不豁免，走「延伸 → 重切 → 下尺」全流程 |

- **挂载密度控制**：重区块与卡口全挂，轻区块少挂——与停拆规则同构：问题不问的层不拆，问题不问的块不挂。
- **机会公式下沉（区块级）**：机会 = **该区块**的现有解法满意度低，且换到你的方案成本低。机会不再是一句链级总判断，而是逐块的局部判断——同一张链上往往几块是机会、几块是陪跑，笼统一句「有机会」掩盖的正是这个。

各组判断的要点沿用（挂到各自的范围上）：

**落差（对象级）**——「想解决的 / 能解决的 / 实际解决的」拆三段：「想 vs 能」落差 = 设计问题，「能 vs 实际」落差 = 落地问题，两种病药方不同；「想解决」原文照录；「实际解决」须有实测证据，无则如实标注。

**在场者（区块级）**——这块上谁已经在解？土办法（用户此刻的凑合办法）是真竞品；满意度要分「骂着用」（有东西拴着，别碰）与「骂完就走」（机会）；切换成本要拆（钱、数据搬家、习惯、关系、重学）；**用户的志**：用户自己想摆脱吗——判据是「摆脱动作」（找过替代、试过工具、花过钱），你替他急不算；**让步的重量**：现有解法解不到的部分，用户怎么让步（忍、绕、拼凑、放弃）——让步越轻剩余痛越不值钱，让步越重切入点越大，让步的重量是剩余市场的刻度；**加分项硬约束**：「解完原痛还顺带……」的额外收益，必须有人为那个加分项**单独**付出过代价才算数，否则只记不评——不许拿「顺带就能」当万能借口；解法两个方向——没解法问「能不能被解决」（不能 = 科学问题非产品问题），有解法问「复制难度」（容易 = 谁都进得去，很难 = 破局资格或出局）；坟场是警告不是蓝海；**抄袭是双向的**：别人好不好被你抄（复制难度），你好不好被别人抄（护城河），两边都查。

**掏钱（对象级三角 + 区块级触发）**——使用者、决策者、付费者逐个指名；不重合时一切动作对准掏钱的那个（话术说给买单的人听）；每块有各自的痛感峰值，收费点贴着触发点。

### 1.3 改善——「下一步做什么？」

分析完毕，收束成两样东西，守两条铁律：

1. **结论不得引入新证据**。收束时只准使用前面查明的事实——防止临场编故事、防止结论逃逸出证据。
2. **行动必须排序并标价**。不许写「加强」「优化」这类不花成本、无法验收的愿望；每条行动要能回答「先做哪个、花多少、怎么算做成了」。

允许一个反直觉的答案：**最好的改善就是不改善**。有的对象，结论就是「停」，行动清单上第一条是「停止投入，成本为零」。

### 1.4 扩展——「链上还能长什么？」

位置定案之后（定在延伸建好的大链坐标系上），沿链向四个方向扫描生长候选：

| 方向 | 含义 |
|---|---|
| **往上游** | 占住排在你前面的区块（做分发的前去做创作） |
| **往下游** | 占住排在你后面的区块（做交易的前去占支付） |
| **并联** | 长出共享同一批资源的旁支（司机与算法可复用，就长代驾） |
| **变形** | 不占新位置，改造链本身：拆、并、增、删 |

生长必须过三道闸，缺一不可：

1. **回炉闸**：每个新候选不享受任何豁免，回到「判定 → 分析」从头全审一遍（延伸、重切、细守、逐块判断一样不少）。生成候选的成本是零，最容易诱发幻觉。
2. **相邻闸**：只许长在与现有位置共享「用户 / 能力 / 资源」的地块上。链上相邻 ≠ 能力相邻——离得近不等于做得成。
3. **优先闸**：同等条件下，优先占卡口，其次占重区块，最后才是轻区块。

**原则：生长负责大胆，分析负责杀。**

### 1.5 附记 · 痛点分析法的并入

独立方法《痛点分析法》（七问漏斗：真的痛吗 / 有多痛 / 有多少人痛 / 有解法吗 / 要解决吗 / 解了多少 / 痛完之后呢）并入本方法，挂载如下：

| 七问 | 并入位置 |
|---|---|
| ① 真的痛吗 | 粗守（原样）+ 细守第一问 |
| ②③ 有多痛 × 有多少人痛 | 细守「量」；强度 × 广度 = 痛的总账 |
| ④ 有解法吗 | 细守「解」→ 下尺在场者的登记起点 |
| ⑤ 要解决吗 | 细守「志」→ 在场者新刻度「用户的志」 |
| ⑥ 解了多少 | 细守「度」→ 在场者新刻度「让步的重量」「加分项硬约束」 |
| ⑦ 痛完之后呢 | 细守「凑」→ 在场者「土办法」（原已有，明确为真实起跑线） |

《痛点分析法》管「这个痛值不值得接」的单点快筛；本方法管接了之后的全流程。两者判据同源（成本是唯一的测谎仪）。

## 2. 贯穿的三个信念

三个信念撑起全部四个动词。动词是手法，信念是魂。

### 2.1 顺序即逻辑

判定 → 分析 → 改善 → 扩展的次序不可交换：

- 痛点不真，谈竞争无意义；
- 空位不在，谈位置无意义；
- 位置不对，谈收钱无意义。

后面的问句永远建立在前一问通过之上。跳序得到的所有答案，都建立在没验证的地基上。范围层的粗细也在次序里：粗守在延伸前，细守在重切后，尺子在定案后——跳层得到的所有答案，同样没地基。

### 2.2 成本是唯一的测谎仪

口号不算数，点赞不算数，情怀不算数——只有「付出过代价的行为」算数。

这套方法里最锋利的判断都源于此：土办法是真竞品（用户已经为它付出了习惯）；骂着用不是机会（他忍的成本低于走的成本）；付费瞬间是痛点发作那一刻（此刻他最愿意掏钱）；阶段边界看锚点不看时长（用户为自己的分段付出了认知）；用户的志看摆脱动作不看嘴上说（行动有成本）；让步的重量量的是用户已经在付的成本；粗守细守两遍都是成本检验（有人付出过代价吗）。分析中的一切疑点，最后都问一句：**有人为它花过什么吗？**

### 2.3 地图会过期

链上的区块会被技术、习惯、政策改变大小——某个区块可能被新工具压扁，价值不消失，迁往相邻区块（支付被压扁后，价值流向了数据与信贷）。递归结构下漂移可以发生在任何层：上层区块被压扁，子链随之重组；区块替换本身是漂移的聚合面（「自煮」被「点外卖」替换时，结构锚「吃饭」不变）。

**漂移也发生在解法上**：新解法会随技术力提升冒出来，旧解法会随技术力提升变强——「没解法」可能只是技术还没到（时间问题，不是科学问题），「解了七成」的剩余空间可能被对手的技术进步直接吃掉。判据限定**现有技术在当前提升速度下的自然延伸**，不预测科幻级跃迁。由此，**机会本身有保质期**——判定时量好的空间，要标上复验时点。

三个推论：

1. **一切结论有保质期**。今天是卡口，明天可能被压平；评估结论要定期重验。
2. **漂移即信号**。「哪一块正在变大」本身就是下一个生长方向的提示——扩展开扫前，先看链上哪里正在隆起。
3. **机会有保质期**。解法层的漂移与技术层的漂移同构：细守与在场者量出的剩余痛空间，必须标注「按当前技术力能守多久、何时复刻」——没标复验时点的机会判断，视为未完成。

## 3. 方法适用什么

- **适用对象**：产品、项目、作品、功能、想法——任何「要不要做、做得对不对、该不该继续」的对象。
- **天生缺口**（诚实声明，使用时须另行补位）：外部约束（政策法规、时机窗口）与执行者能力（同一想法换人做，结论应当不同）不在这套方法的地基里；**方法论类对象**（用这套方法分析这套方法自身）的守门适用性同样未建立。这不是疏漏的装饰，是本方法边界的如实标注。

---

## 4. 方法不承诺什么

- 本方法的全部公开案例来自已知成败的商业史，属于**事后归纳**；它的事前预测力尚无验证记录。
- 本方法不保证结论正确，只保证**结论有据可查、行动可验收**——它的价值在防幻觉，不在预言。
